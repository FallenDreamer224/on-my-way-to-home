# Project instructions

Project: On My Way to Home. Use Godot 4.7.2 and typed GDScript where practical. This is a fully native 2D isometric game. Keep work within the requested phase and project directory; preserve unrelated configuration and instructions.

## Required visual asset workflow

1. Before creating, importing, or preparing requests for any visual asset, read `docs/ART_BIBLE.md` and `art/asset_standards.json`. Follow both; keep their standards version and specifications in agreement when an explicitly requested revision changes them.
2. Apply these standards to manual asset briefs and PixelLab.ai MCP generation requests. Read `docs/isometric_standards.md` for grid/alignment conventions and `assets/pixellab/README.md` for intake/provenance rules.
3. Validate actual dimensions, native scale, direction coverage/mapping, anchors, and animation metadata before integrating assets into Godot. Check each directional clip's actual frame count and frame regions; never assume equal counts or infer sheet order from a direction list. The existing intake manifest is a template and must be completed to meet the official metadata requirements.
4. Never silently resize, stretch, crop, or distort generated or manual artwork to force compliance. Preserve original sources. Report incompatible assets and request a user decision before modifying them or integrating them through an exception. Document every exception's dimensions, intended use, rationale, and approval.
5. Keep gameplay systems independent of final artwork wherever possible. Prefer modular scenes, typed configuration, and placeholders until artwork is approved; do not implement unrequested gameplay systems.
6. Never generate PixelLab assets, submit generation jobs, or consume credits without explicit user authorization. Preparation of standards or generation prompts alone does not authorize generation.
7. Keep all project documentation, code comments, game content, and asset names in English. Use lowercase snake_case for new asset names.
8. Preserve existing project instructions and unrelated rules when updating this file. Report conflicts between standards or instructions; do not silently replace established decisions. Direction codes N/NE/E/SE/S/SW/W/NW map to the existing long names as defined in the Art Bible; list order is not sheet order.
