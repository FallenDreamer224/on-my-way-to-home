# Contributing

The project is in a demo scope freeze. Code/art licensing and contributor terms have not yet been selected, so unsolicited code or artwork submissions are not currently requested.

Bug reports should name the Godot version, reproduction steps, expected/actual behavior and relevant error categories. Do not publish API keys, account information, personal paths, private checkpoints or entire development profiles.

For authorized work:

- Read AGENTS.md and the current demo readiness report; keep the assigned phase narrow.
- Preserve native 2D, 64x32 isometric terrain, 960x540 UI and existing artwork.
- Use typed GDScript where practical. Keep asset quantities/state out of UI widgets.
- Read the locked art/science standards before relevant changes.
- Do not generate PixelLab assets, consume credits, add audio, rewrite history, commit or publish without authorization.
- Run the headless and graphical validation procedures described in README.md.
- Keep .uid and .import settings. Exclude caches, credentials, local editor settings, builds and test outputs.
- Treat a new game license or art redistribution permission as an explicit publisher decision.

A GitHub workflow, pull-request policy and contributor license agreement have not been invented for this uninitialized local repository.
